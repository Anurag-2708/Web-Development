We will use the anchor (a) element to create links. We have to add the link as attribute using href for it to actually work. By default target is _blank meaning link will open in current tab. By making target as _blank we will open link in new tab/window depending on browser settings. Attributes go inside the opening tag of an element and each attribute as two parts a name and value but however not all attributes require a value.

rel attribute should be added for security and privacy when using _blank. Values of rel attribute are:

  • rel='noopener': The new tab opened cannot interact with the original tab. This is very crucial to prevent phising attacks, as without this JavaScript can be used in new tab to manipulate and modify original tab.
  • rel='noreferrer: The new page wont know where the user came from. Basically it hides the referrer.

Absolute links: links to other website and require scheme://domain/path
Relative links: links to other pages in your website and require only file path to other page
