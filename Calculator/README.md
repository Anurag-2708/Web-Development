# Calculator

This project is a fully functional, keyboard supported calculator built to handle complex mathematical expressions. 
It was created as a part of my **Web Development** learning journey following the [The Odin Project](https://www.theodinproject.com) curriculum.

Link to Project 👉 [Calculator](https://anurag-2708.github.io/Web-Development/Calculator/index.html)

## Key Features
- **Mathematical Precedence:** Supports standard order of operations using the Shunting Yard algorithm.
- **Keyboard Support:** Full input mapping for keys like Enter, Backspace, and operators.
- **Implicit Multiplication:** Handles expressions like `5(10)` automatically.
- **Floating Point Fix:** Correctly manages JavaScript's decimal precision issues.

## Technical Implementation
The primary goal of this project was to master **DOM manipulation** and **state management**. To ensure mathematical accuracy, a stack-based parser was implemented to handle operator precedence and parentheses. This architecture allowed me to focus on creating a robust input logic system that prevents invalid mathematical entries.
