# Signup Form

This project is a fantasy-themed signup form built as part of The Odin Project Foundations curriculum. It combines modern form validation techniques with custom styling and world-building elements to create an immersive user experience.

Link to Project 👉 [Thunder's Kingdom](https://anurag-2708.github.io/Web-Development/Signup_form/index.html)

## Features

* **Fantasy-Themed Design:** Custom medieval-inspired UI featuring fantasy artwork, custom typography, and a kingdom-themed aesthetic.
* **Form Validation:** Required field validation using HTML5 form attributes combined with custom JavaScript password confirmation checks.
* **International Phone Support:** Phone number input with selectable country codes for multiple countries.
* **Custom Typography:** Locally hosted custom fonts loaded using `@font-face` for a unique visual identity.
* **Submission Feedback:** Successful submissions hide the form and display a custom citizenship acceptance message.
* **Responsive Layout:** Split-screen layout with a promotional hero section and a structured form interface.

## Technical Implementation

This project was primarily used to practice form creation, validation, and advanced CSS layout techniques. The page is divided into two main sections using Flexbox: a hero panel featuring custom branding and artwork, and a form panel built with CSS Grid.

Additional focus was placed on visual presentation through the use of custom fonts loaded locally via `@font-face`, layered backgrounds, gradients, shadows, and themed content to reinforce the fantasy setting of Thunder's Kingdom.
