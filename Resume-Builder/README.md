# Resume Builder

This project is a modern, interactive resume builder developed using **React**. It enables users to create professional resumes through a structured editor while simultaneously viewing a live A4 formatted preview. The application was built as part of my **Web Development** learning journey following the **Full Stack JavaScript** path of [The Odin Project](https://www.theodinproject.com).

## Key Features

- **Live Resume Preview:** Every change made in the editor is reflected instantly in a professionally formatted A4 resume preview.
- **Dynamic Resume Sections:** Add, edit, and remove multiple Education, Experience, and Project entries with automatic UI updates.
- **Structured Resume Editor:** Dedicated editors for Personal Information, Summary, Education, Experience, Projects, and Skills keep the editing experience organized.
- **Responsive Layout:** Optimized layouts for both desktop and mobile devices, providing an intuitive editing experience across screen sizes.
- **Professional Resume Formatting:** Clean typography, section dividers, aligned content, and print friendly A4 styling designed for modern resumes.
- **Component-Based Architecture:** Built with reusable React components to improve maintainability and scalability as new resume sections and templates are added.

## Technical Implementation

The primary focus of this project was learning **React fundamentals**, **component-based architecture**, and **state management**.

The application follows a centralized state management approach where the main application component owns the resume data and passes it down to child components via props. Dynamic sections such as Education and Experience are implemented using immutable state updates with JavaScript's `map()` and `filter()` methods. Every dynamically created resume entry is uniquely identified using the native `crypto.randomUUID()` API, allowing efficient rendering and deletion through React's reconciliation process.

The project emphasizes reusable components, controlled form inputs, responsive CSS layouts, semantic HTML, and scalable application architecture suitable for future enhancements such as multiple resume templates, PDF generation, LaTeX export, drag-and-drop section ordering, and theme customization.
